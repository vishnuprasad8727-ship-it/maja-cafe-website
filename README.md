# Maja Cafe Website

A responsive Flask website for Maja Cafe, Kozhikode, built from the menu images supplied by the owner/user.

## Run locally

```bash
python -m venv venv
# Windows: venv\Scripts\activate
# macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000

## GitHub

Upload the whole folder to a GitHub repository. For free deployment, you can connect the repository to Render or another Flask-compatible hosting service.

## Important

The phone numbers, address, menu items and prices in this demo are transcribed from the supplied images. Verify them before publishing.
